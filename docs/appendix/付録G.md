## 付録G：バージョン履歴

本付録は、本資料の改訂履歴を記録するものである。各版の変更内容、構成の対応関係、および版数の付与基準を示す。

* * *

### 版数の付与基準

| 形式 | 条件 | 該当例 |
| --- | --- | --- |
| 整数の更新（1.0→2.0） | 全体構成の再編を伴う改訂 | Ver 2.0 |
| 小数点の更新（1.0→1.1） | 章・節の新設を伴う改訂 | Ver 1.1 |
| 枝番の付与（2.0→2.0a） | 構成変更を伴わない追記・修正 | Ver 1.0a、Ver 2.0a |

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年8月16日 |
| 微調整・品質検証 | Claude Opus 5 |
| 概要 | 老衰死時のテンポラレル挙動を明記。本編の構成変更なし |
| 構成 | 6部13章＋付録A〜G（変更なし） |

| 変更内容 | 詳細 |
| --- | --- |
| 第8章 第5節 追記 | 老衰死の表に「時間の巻き戻り：発生しない」を追加。制約一覧の老衰死の行に巻き戻り不発生を明記 |
| 第9章 第7節 追記 | 各転送状態の挙動表に老衰死の行を追加。断絶が発生しないためテンポラレルが作動しないことを本文に明記 |
| 第9章 第7節 改訂 | フローチャートの冒頭に死因の分岐を追加。老衰死を意識判定より前で分離し、巻き戻り経路から除外 |
| 付録F 改訂 | Eカテゴリ「老衰で死んだ場合はどうなりますか？」の回答に巻き戻り不発生を追記 |
| 付録F 追記 | Fカテゴリに「老衰死でもテンポラレルは作動しますか？」を追加（11カテゴリ・全72問） |
| 付録G 改訂 | 版数の付与基準を新設。旧付録B（FAQ）と現付録B（数値・定数一覧）の記号衝突を解消するため「付録B（当時）」表記に統一。Ver 2.0欄の誤記を修正 |

#### 改訂の背景

Ver 2.0までの記述では、老衰死について「逆命令信号が発動しない」というリヴァイブ側の説明のみが存在し、テンポラレル側の挙動が未言及であった。第9章7節が「テンポラレルはリヴァイブの成否に関係なく作動する」と規定しているため、この状態では老衰死がダイブエラーと同様に「時間だけ巻き戻る」と解釈される余地が残っていた。本改訂により、両者の差異が「断絶の有無」にあることを明示した。
